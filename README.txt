ABN.CAPTAIN — FREE HOSTING PACKAGE

This is a static website and can be hosted free with GitHub Pages.

1. Create a GitHub account at github.com.
2. Create a PUBLIC repository named: abn-captain
3. Upload ALL files from this folder to the repository root.
4. Go to Settings -> Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Your site will be:
   https://YOUR-USERNAME.github.io/abn-captain/

IMPORTANT:
- Replace YOUR-USERNAME in robots.txt and sitemap.xml with your actual GitHub username.
- After publishing, submit your live URL in Google Search Console.
- The current premium buttons are presentation placeholders; payment/backend features are not connected yet.
- Sample player codes in the MVP must be replaced with verified codes before publishing them as real player settings.
